# Edenemisraport



## Mis on valmis

- [x] Docker Compose käivitab kõik teenused
- [x] Andmeid saadakse allikast kätte
- [x] Andmed laetakse `staging` kihti
- [x] Vähemalt üks transformatsioon toimib
- [x] Vähemalt üks näidikulaud on nähtaval
- [x] Vähemalt üks andmekvaliteedi test läbib

Projektis on valmis andmevoog algusest lõpuni. Andmete sissevõtt on korratav ning laadimine toimub üks kord päevas.
Andmed saame kahest erinevast allikast. Andmed on muudetud analüüsiks sobivaks, tehtud on tüübiteisendused 
nt timestamp'l põhinevad veerud on datetime formaadis ning arvutatavad veerud on measure formaadis. 
Esmased visualiseeringud on tehtud Tableaus, kus on arvutatud korrelatsioonid korrelatsiooni valemite abil. 
Tableaus on visualiseeritud KPI-d (korrelatsioonid) ja graafikud (korrelatsioon kuude ja riikide lõikes). 

## Järgmised sammud

- Testide ülevaatamine
- Erinevate KPI-de ja graafikute vahel valimine, mida kuvada lõplikul dashboardil
